# 05 — Marketing & Launch

## 1. How games grow on Roblox

1. **Algorithm (biggest lever).** Roblox recommends games with strong retention, playtime, and engagement. Great metrics → free homepage traffic.
2. **Social spread.** Friends inviting friends; co-op design makes this natural.
3. **Short-form video.** TikTok, YouTube Shorts, Reels. Clips of panic and rare drops.
4. **Creators.** Roblox YouTubers/TikTokers playing the game.
5. **Paid ads.** Roblox sponsored experiences and ads; best for seeding traffic, not sustaining it.

## 2. Pre-launch (during development)

- [ ] Reserve names: Roblox group, TikTok, YouTube, X, Discord
- [ ] Post dev clips 2–3×/week from Phase 1 onward (grey-box chase scenes still work)
- [ ] Grow Discord to a few hundred members for beta testing
- [ ] Build a "press kit" folder: logo, icon, 10 screenshots, 30 s gameplay clip, one-paragraph pitch

## 3. Store page optimization

- **Icon:** one character or creature face, high contrast, readable at tiny size. Test 2–3 versions.
- **Thumbnails:** action moments (creature chasing diver with glowing relic). Test variants.
- **Title:** "Deep Salvage" + a short emoji/tag during events (e.g., "Deep Salvage 🎃 GHOST TIDE").
- **Description:** first line hooks ("Dive, loot, survive — can you make it back up?"), then update notes and codes.

## 4. Soft launch (Phase 5)

- Budget idea: a few thousand Robux of sponsored ads, spread over a week.
- Goal is **data**, not growth: retention, FTUE funnel, crashes.
- Fix, re-test, repeat. Only scale once targets hit (D1 ≥ 25%, session ≥ 15 min).

## 5. Growth launch (Phase 6)

### 5.1 Creator program
- Target creators with **50k–500k followers** who post Roblox horror/survival content. Better engagement per dollar than huge creators.
- Offer: early access, custom in-game title/cosmetic, creator codes, and (if budget allows) paid sponsorship.
- Make it easy: send a 1-paragraph pitch, a join link, and suggested "challenge" ideas ("Can 4 YouTubers survive the Warden?").
- Give creators a private server and a unique code whose uses you can track.

### 5.2 Short-form content plan
Post daily for the first month. Content types that clip well:
- Near-death extractions with seconds of oxygen left
- Legendary mutation reveals
- Friends screaming at a Lurker ambush (proximity voice)
- "POV: you got greedy" memes
- Lore teasers and hidden-room discoveries
- Dev behind-the-scenes

Build a quick in-game **clip mode** (hide UI, dramatic camera) to make player-made content easier.

### 5.3 Community
- Discord channels: announcements, update leaks, codes, bug reports, fan art, lore theories.
- Weekly sneak peeks the day before updates.
- Codes at like/favorite milestones ("10K likes → code for 500 Coins").
- Reward fan art and theories with in-game shoutouts or cosmetics.

## 6. KPIs dashboard

| Metric | Why it matters | Early target |
|---|---|---|
| D1 retention | Is the first session good? | ≥ 25% |
| D7 retention | Is there a long-term hook? | ≥ 8% |
| D30 retention | Live ops working? | ≥ 3% |
| Avg session length | Algorithm weight | ≥ 15 min |
| Sessions per DAU | Return habit | ≥ 1.5 |
| FTUE completion | Onboarding quality | ≥ 70% reach first extraction |
| % dives in squads | Social loop working | ≥ 40% |
| CCU trend | Overall health | Growing week over week |
| Like ratio | Sentiment | ≥ 85% |

Review weekly. When a number drops, find the cause in the funnel before adding new content.

## 7. Launch-week checklist

- [ ] All analytics events verified in Creator Dashboard
- [ ] Content maturity questionnaire complete
- [ ] Icons/thumbnails final, variants ready for testing
- [ ] Discord open, codes prepared
- [ ] 7 days of short-form clips pre-made
- [ ] Creator outreach sent 2 weeks before
- [ ] Hotfix plan: who's on call, how to roll back a publish
- [ ] First two weekly updates already built (don't launch with an empty pipeline)
